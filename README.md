Project: Hangman Game

Description

Hangman is a simple word-guessing game developed using Python. The player guesses letters to find a randomly selected word.

Features

- Random word selection
- Six incorrect attempts allowed
- Displays guessed letters
- Checks repeated and invalid guesses
- Shows win or game-over messages

Technologies Used

- Python
- Random module

How to Run

1. Install Python.
2. Run "hangman.py".
3. Guess one letter at a time.
